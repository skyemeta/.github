# Skye Meta

**One membership. Recognized everywhere.**

Skye Meta builds condition-based access products: a membership pass a community issues once, recognized by websites, stores, point of sale and AI agents. Every product here is built on [InsumerAPI](https://insumermodel.com/developers/), which reads a wallet, checks a condition and returns a signed yes or no that anyone can verify.

## Open source

| Repo | What it does |
|---|---|
| [agenttalk](https://github.com/skyemeta/agenttalk) | Condition-gated sessions for AI agents. Every agent proves its wallet and meets the same on-chain conditions before the session opens; re-verify on demand, and whoever stops qualifying is removed. |
| [skyegate-sdk](https://github.com/skyemeta/skyegate-sdk) | `@skyemeta/skyegate`: wallet-verified gated content for Next.js and Vercel, on a SkyeGate Pro license. |
| [skyegate-nextjs-starter](https://github.com/skyemeta/skyegate-nextjs-starter) | A minimal Next.js app using `@skyemeta/skyegate`. Clone it or deploy it to Vercel in one click. |
| [skyemeta-access](https://github.com/skyemeta/skyemeta-access) | `@skyemeta/access`: add wallet sign-in to your API beside your existing API keys. Free, MIT, bring your own InsumerAPI key. |
