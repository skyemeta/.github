# Getting help

- **Bugs and feature requests:** open an issue in the repository concerned.
- **Security issues:** use **Report a vulnerability** on the repository's Security tab. Please do not open a public issue.
- **License, billing and account questions:** support@skyemeta.com.
- **Documentation:** [skyemeta.com/developers](https://skyemeta.com/developers/) and [InsumerAPI docs](https://insumermodel.com/developers/).
